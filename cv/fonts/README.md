# Fonts for the CV

XCharter (Roman, Bold, Italic, Bold Italic, OpenType), from CTAN's `xcharter` package
(https://ctan.org/pkg/xcharter), so the CV workflow builds the PDF with the font the
`.typ` asks for (`typography-font-family-*: "XCharter"`), the same on every run.
